# PDF Export Workflow (Pandoc + XeLaTeX)

This repository exports four publication-ready reports using a reproducible Pandoc + XeLaTeX pipeline.

## Prerequisites

- `pandoc`
- `xelatex` (TeX Live / MacTeX)

### Ubuntu / Debian

```bash
sudo apt-get update
sudo apt-get install -y pandoc texlive-xetex texlive-latex-extra fonts-texgyre
```

## Build all report PDFs

From repository root:

```bash
chmod +x scripts/build_reports_pdf.sh
./scripts/build_reports_pdf.sh
```

## Output artifacts

Generated files are written to `pdf/out/`:

- `AI_Safety_RedTeam_Report.pdf`
- `Breast_Cancer_Classification_Report.pdf`
- `LLM_Ensemble_Bias_Detection_Report.pdf`
- `RAG_Project_Report.pdf`

## Notes

- The XeLaTeX template is `pdf/ieee-report-template.tex`.
- Section numbering and TOC are generated by Pandoc for consistent hierarchy.
- If you edit report markdown sources, rerun the script to regenerate PDFs.
