AI Safety Red-Team Evaluation

How can safety evaluation scale beyond manual review?

  • Two-stage design: an LLM ensemble labels 12,500 response pairs, then a supervised classifier learns those labels.
  • Reports annotation agreement separately from classifier accuracy, so a strong model cannot hide weak labels.
  • Bayesian hierarchical risk analysis and SHAP attribution support audit-oriented reporting.

Accuracy is measured against the ensemble's labels, not human-verified ground truth. Not a substitute for expert red-teaming.

Breast Cancer Classification Benchmark

Which ensemble methods perform well on WDBC diagnostic features?

  • Benchmarks eight ensemble classifiers on the 569-sample Wisconsin Diagnostic Breast Cancer dataset.

LLM Ensemble Textbook Bias Detection

Can multiple LLM judges support uncertainty-aware content review?

  • Rubric-based ratings from an LLM ensemble across 4,500 passages, with agreement measured before any aggregation.
  • Bayesian partial pooling makes group-level uncertainty visible, with MCMC diagnostics reported.
  • Routes disagreement and high-uncertainty passages to expert review.

Publishers are anonymized placeholders and no real textbooks were analyzed. Findings are not a claim about any real publisher.

RAG Production Pipeline

How can retrieval, grounding, and monitoring improve RAG system design?

  • Hybrid retrieval combining dense vectors and BM25, followed by ColBERT re-ranking.
  • Evaluates retrieval separately from generation, then checks citation grounding and calibrates answer confidence.
  • Specifies the monitoring, drift detection, privacy safeguards, and rollback a production deployment would need.

A systems-design case study. Metrics come from a simulated evaluation, not a live service.
