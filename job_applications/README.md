# Job Applications Tracker

Daily rolling log of curated openings — 5/day, NYC or remote — with tailored pitches mapping each role to Derek's 3 primary projects:

- **P1 — AI Safety Red-Team Evaluation**
- **P2 — LLM Ensemble Bias Detection**
- **P3 — Breast Cancer ML Classification**

## Files

- `YYYY-MM-DD.md` — one file per day, 5 openings each, with link, project mapping, cover-letter pitch, and lead resume bullets.
- Update the status marker (`[ ]` → `[x]` / `[~]` / `[-]`) as applications move.

## Workflow

1. Open today's file, verify each link is still live, and submit through the company's ATS.
2. Paste the pitch into the cover-letter box and pull the lead bullets into a role-tailored resume version.
3. Flip the status marker so the next day's routine skips duplicates.
