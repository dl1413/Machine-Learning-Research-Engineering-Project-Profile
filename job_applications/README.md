# Job Applications

This directory holds daily application packages generated by a scheduled routine
that turns the three portfolio projects into tailored, submission-ready
materials for five NYC-or-remote openings per day.

## Layout

```
job_applications/
  README.md                    This file
  YYYY-MM-DD/
    INDEX.md                   Day's five leads with links + status checklist
    01_<company>_<role>.md     Cover letter + project selection + submission notes
    02_<company>_<role>.md
    ...
```

## How to use

1. Open `YYYY-MM-DD/INDEX.md` — it lists the five leads, the direct posting
   URL, the three projects highlighted for each, and a checklist you tick off
   as you actually submit.
2. Copy the cover-letter body from each per-role file into the employer's
   application form (or send by email where the file says).
3. Attach the résumé (`Resume_Derek_Lankeaux.md` or the PDF export) and any
   project PDFs the letter names.
4. Update the checklist so the next day's run doesn't repeat leads.

## Scope of automation

The routine drafts materials and points to live postings; it does not
authenticate to job boards or submit applications on the candidate's behalf.
Every submission is a manual step by Derek.
