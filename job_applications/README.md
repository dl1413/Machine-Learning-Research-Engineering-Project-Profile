# Daily Application Packets

This folder holds day-by-day "application-ready" packets generated for Derek Lankeaux's job search — 5 target roles per day in **NYC or Remote**, each mapped to the 3 primary portfolio projects.

## What each packet contains

For each of 5 target roles per day:

1. **Company & role** — with careers-page link (job req IDs change frequently; verify the specific opening before applying)
2. **Why this fits** — 2-3 sentence match summary
3. **Which 2 projects to lead with** — from AI Safety Red-Team / LLM Bias Detection / Breast Cancer Classification
4. **Tailored cover-letter draft** — ready to paste, personalize the opening line, and send
5. **Resume tweaks** — 1-2 bullet swaps to align with the JD keywords
6. **Talking points for phone screens** — 3 bullets

## How to use a packet

1. Open the daily file for today's date
2. For each of the 5 roles, click the careers link, filter for the role type described, and confirm the requisition is open
3. Copy the cover-letter draft, replace `{{HIRING_MANAGER}}` / `{{ROLE_TITLE}}` / `{{REQ_ID}}` placeholders
4. Apply the resume-tweak suggestions on `Resume_Derek_Lankeaux.md` (keep the base file clean — export a role-specific copy)
5. Submit through the company's ATS

## Rotation strategy

To avoid re-targeting the same 5 companies every day, packets rotate across these buckets:

- **AI safety / eval labs** (Anthropic, OpenAI, Scale, Cohere, SaferAI, Apollo, METR, Hugging Face)
- **Healthtech / biotech ML** (Flatiron Health, Tempus, Recursion, Insitro, Cedar, Ro)
- **Fintech / risk DS** (Two Sigma, Point72, Ramp, Brex, Stripe, Plaid)
- **Big Tech applied science** (Google, Meta, Amazon Applied Science, Netflix)
- **AI-native startups** (Perplexity, Character, Runway, Hebbia, Harvey, Cursor)
- **Edtech / responsible AI** (Khan Academy, Coursera, Duolingo, McGraw Hill)

Each day pulls ~1 role from a rotating subset to maximize coverage without repetition.

## Important caveats

- **These are packets, not submissions.** Derek submits each application himself. Automated submission would violate every major job-board ToS and route around EEO / work-authorization / salary-expectation fields that must be answered truthfully by him.
- **Job listings change fast.** Every careers-page link is verified against the company's known 2026 hiring, but a specific req can close between packet generation and submission. If a listed role is gone, look for the closest equivalent on the same page.
- **First-pass drafts.** Cover letters here are 80% of the way — Derek should add one sentence of specific enthusiasm (something he read on the team blog, a paper the team wrote, etc.) before sending.
