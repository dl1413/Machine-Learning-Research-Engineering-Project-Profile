# Job Applications — Daily Output Root

This folder holds the daily 5-application output generated by the scheduled
routine that runs each day and prepares tailored cover letters using the
three primary projects:

1. **AI Safety Red-Team Evaluation** — 96.8% accuracy, 340× cost reduction,
   Krippendorff's α = 0.81 across GPT-4o / Claude-3.5 / Llama-3.2
2. **LLM Ensemble Textbook Bias Detection** — 67,500 ratings, α = 0.84,
   Friedman χ² = 42.73 (p < 0.001), PyMC hierarchical (R-hat < 1.01)
3. **Clinical-Grade Breast Cancer Classification** — 99.12% accuracy, 100%
   precision, ROC-AUC 0.9987, SHAP + FastAPI < 100ms p95

Geo filter: **New York City** (on-site/hybrid) or **US remote**.

Cadence: 5 tailored applications per day (Mon–Fri = 25/week).

## Layout

```
job_applications/
├── README.md                 ← this file
├── application_tracker.csv   ← durable log; append 5 rows/day at submit time
└── YYYY-MM-DD/               ← one folder per day
    ├── README.md             ← daily index: 5 roles + links + checklist
    ├── 01_<company>_<role>_cover_letter.md
    ├── 02_...
    ├── 03_...
    ├── 04_...
    └── 05_...
```

## How to use each day

1. Open the day's `README.md` — it lists the 5 roles with apply links, notes on
   which are stretch/mid-level, and the top-3 resume bullet order per role.
2. For each role: click apply, paste cover letter (or upload as PDF), reorder
   resume top-3 bullets to match, answer work-auth + salary, submit.
3. Append a row to `application_tracker.csv`.
4. If a JD is gone, note it in the daily README and swap in an adjacent role.

## Anti-fabrication rule

Every metric in these cover letters is drawn from the three published technical
reports in this repo — nothing invented. If a figure feels off during review,
cross-check against the source report before submitting.
