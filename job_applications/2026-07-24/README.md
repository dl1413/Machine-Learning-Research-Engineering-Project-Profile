## Routine

Total time budget: **~90 minutes**.

1. **Sourcing (15 min).** Open each target_list link, shortlist 1 specific
   posting per role family. Note company + JD link in the tracker.
2. **Tailor (10 min per app x 5).** For each shortlisted role, open the matching
   cover letter, replace `[Company]` and `[Team/Product]`, pull 2-3 JD keywords
   into the opening line, and confirm the "why this project matters here" beat
   still reads correctly.
3. **Submit (5 min per app x 5).** Attach the current resume PDF, paste the
   cover letter, submit, log the timestamp in the tracker.
4. **Followups (10 min).** Any warm contacts at the 5 companies → LinkedIn note
   referencing the same project detail from the cover letter.

Stop at 5. The compounding win is one clean pass per day for 20 business days,
not a marathon.
